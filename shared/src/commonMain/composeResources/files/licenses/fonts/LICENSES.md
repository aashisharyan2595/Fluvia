# Bundled font licences

The selectable fonts are bundled unmodified as the static TrueType files published in the `@expo-google-fonts/<name>` npm packages (Google Fonts releases). The wrapper packages are MIT; every font is licensed under the SIL Open Font License 1.1, copied below with each font's copyright line. Fonts with a single published weight use it for both regular and bold.
